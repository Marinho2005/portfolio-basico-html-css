# portfolio-react

Projeto convertido de HTML/CSS/JS para React + Vite + TypeScript.

Como usar:

1. Instale dependências:

```bash
cd portfolio-react
npm install
```

2. Copie os assets do projeto antigo para a pasta `public`:

```bash
npm run copy:assets
```

3. Rode o servidor de desenvolvimento:

```bash
npm run dev
```
